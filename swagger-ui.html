📝 Memory API - Documentation

API RESTful pour la gestion de notes avec authentification JWT

🔐 Authentification

Pour utiliser l'API, vous devez d'abord vous authentifier :

  1. Utilisez l'endpoint POST /memory/login avec vos identifiants
  2. Récupérez le token JWT dans la réponse
  3. Cliquez sur le bouton "Authorize" ci-dessous et entrez : Bearer {votre-token}
  4. Vous pouvez maintenant tester tous les endpoints protégés

Exemple de requête de login :

curl -X POST "http://localhost:8000/memory/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "votre-username",
    "password": "votre-mot-de-passe"
  }'

🚀 Serveurs disponibles

  • Développement local : http://localhost:8000/memory
  • WAMP local : http://localhost/memory

📚 Ressources principales

  • Users - Gestion des utilisateurs et de leurs profils
  • Notes - Création, modification et partage de notes
  • Projects - Organisation des notes par projets
  • Tasks - Gestion des tâches avec système Kanban
  • Comments - Commentaires sur les notes
  • Tags - Classification des notes par tags
  • Uploads - Gestion des fichiers uploadés
